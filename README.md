# 🛡️ Firewall Blocked Traffic Analysis

### SOC Analyst Mini Project | Splunk

A Security Operations Center (SOC) mini project focused on analyzing **firewall-blocked network traffic using Splunk** to identify suspicious source IPs, targeted internal systems, and potential reconnaissance activity.

## 🎯 Objective

Analyze firewall logs to:

- Identify the **top source IP generating blocked traffic**
- Determine the **targeted internal IP/asset**
- Analyze blocked connection patterns
- Separate suspicious activity from normal network traffic
- Support SOC investigation and incident triage

## 🔍 Key Findings

The analysis helped identify:

- The **most active suspicious source IP**
- The **internal system receiving the highest number of blocked connections**
- Repeated connection attempts indicating possible **network probing/reconnaissance**
- Frequently targeted ports and services
- Patterns that could help a SOC analyst prioritize an investigation

## 🛠️ Tools & Technologies

- **Splunk**
- Firewall Logs
- SPL (Search Processing Language)
- Network Security Analysis
- Threat Detection
- SOC Investigation

## 📊 Analysis Performed

The project uses Splunk searches to analyze:

- Blocked vs allowed traffic
- Source IP activity
- Destination IP activity
- Destination ports
- Event frequency
- Top attackers and targeted assets
- Time-based traffic patterns
